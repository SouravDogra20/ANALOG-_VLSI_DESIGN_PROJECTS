# CMOS Inverter Design

## Project Overview
Design and simulation of a CMOS inverter using Cadence Virtuoso.

## Technology Details
- Technology: GPDK180
- Technology Node: 180 nm
- Supply Voltage: 1.8 V
- Design Tool: Cadence Virtuoso IC6.1.8

## Circuit Components
- PMOS transistor
- NMOS transistor
- Input voltage source
- DC power supply

## Simulation Analysis
1. DC Analysis – Voltage Transfer Characteristics (VTC)
2. AC Analysis – Voltage Gain and Frequency Response
3. Transient Analysis – Input and Output Waveforms
4. Propagation Delay – tPHL and tPLH
5. Power Dissipation
6. Operating Point Analysis
